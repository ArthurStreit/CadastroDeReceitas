# Cadastro de Receitas

Aplicação web desenvolvida com Laravel para cadastro e gerenciamento de receitas.

O projeto foi criado com o objetivo de praticar o desenvolvimento de aplicações utilizando o framework Laravel, trabalhando com estrutura MVC, rotas, banco de dados e interface web.

## Tecnologias utilizadas

- PHP
- Laravel
- JavaScript
- CSS
- HTML
- Composer

## Funcionalidades

- Cadastro de receitas
- Visualização das receitas cadastradas
- Gerenciamento das informações das receitas
- Persistência dos dados em banco de dados

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/ArthurStreit/CadastroDeReceitas.git
```

Entre na pasta do projeto:

```bash
cd CadastroDeReceitas
```

Instale as dependências:

```bash
composer install
```

Crie e configure o arquivo `.env`, principalmente as informações de conexão com o banco de dados.

Gere a chave da aplicação:

```bash
php artisan key:generate
```

Execute as migrations:

```bash
php artisan migrate
```

Inicie o servidor de desenvolvimento:

```bash
php artisan serve
```

Depois disso, acesse o endereço informado pelo Laravel no terminal.
